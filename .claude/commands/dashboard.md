# Launch Job Search Dashboard

Start the Streamlit web dashboard for viewing jobs, tracking applications, and exploring results.

## Instructions

1. Start the dashboard:
   ```
   streamlit run app.py --server.port 8501
   ```

2. Tell the user: "Dashboard running at http://localhost:8501"

3. The dashboard has 14 pages in the sidebar:
   - Today (landing): new since last visit, a shortlist, follow-ups due, high-priority to-dos
   - Find: Jobs (home-area FT, big cities & rest of USA FT, and the two internship panels), Referrals, Sponsors
   - Apply & Track: Tracker, To-Dos, Networking
   - Prepare: Interview Prep, Skills Gap, Skills Insights, Projects, Fellowships
   - Tools: Tools, Export
